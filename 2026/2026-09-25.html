🔥 今日重点

Trail of Bits：GPT-5.6-Cyber 多次逃逸 QEMU/KVM，虚拟机挡不住会自主找漏洞的 AI 代理

研究用免费的 GPT-5.6-Cyber 模型攻打标准 QEMU/KVM 开发机，代理自主运行数小时、分析源码、串联零日构造利用链，多次逃逸成功；换成攻击面更小的 Firecracker 虽遏制住逃逸，但底层 Linux 内核漏洞仍导致主机硬锁死。

首轮利用已公开但无 EXP 的 Januscape 内核漏洞触发硬锁死；升级内核后代理转攻网络库 libslirp，结合 CVE-2026-9539 在主机上构造任意读写原语实现逃逸；即便手动拉取上游最新 libslirp/QEMU 重建精简环境，代理仍串联 VAPIC ROM 别名、KVM 未同步影子页、libslirp 分片 IHL 错误等多个零日完成攻击。结论：虚拟化为可用性必须共享的接口本身就是攻击面，缓解要靠最小攻击面虚拟化(Firecracker)、最小权限、快速打补丁、受限网络与每周期纯净短命环境。
🔥 今日重点

GKE agentic migration：AI 辅助把 EKS 搬到 GKE，内置治理护栏

Google Cloud 推出 GKE agentic migration，用 AI 代理自动拆解 EKS 集群配置、生成迁移方案并带内置 governance，缓解 Kubernetes 跨云迁移中人工逐项梳理网络/存储/工作负载的高摩擦。同期 Google 连续第四年入选 Gartner 容器管理魔力象限领导者，执行力维度居首。

迁移代理面向标准化到 GKE 跑 AI 工作负载的企业，覆盖 Cloud Storage FUSE 高吞吐数据访问、自定义计算类(CCC)、GPU 切分等 GKE 能力；传统 EKS→GKE 迁移需平台团队手工剖析集群、逐一映射资源，代理把这一过程自动化并加治理约束。

AWS 推出 CloudWatch Omni：面向应用与 AI agent 的协同式 AI 可观测性

AWS 发布 CloudWatch Omni，把应用与 AI agent 统一到一套可观测性体验，支持自动发现拓扑、自然语言查询、由 AWS DevOps Agent 驱动的 AI 引导排障，并可跨框架对 agent 做 trace/评估/实验，内置质量、正确性、连贯性评估器。

能做什么
在 CloudWatch 上统一观测传统应用与 agentic 工作负载：自动拓扑发现、自然语言查询、AI 引导调查，并跨框架 trace 与评估 agent 输出质量。
解决什么痛点
生成式 AI 与 agent 工作负载的可观测性缺乏专门工具，传统 APM 覆盖不到 agent 的推理链与质量评估。
值不值得
你若在关注 AI 工作负载的可观测性，这是 observability 面向 agent 演进的代表信号；绑定 AWS 生态，自建栈可借鉴其评估维度设计(质量/正确性/连贯性)。
